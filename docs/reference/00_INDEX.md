## 1. What the bot is

**Hangeul BOT** is a Telegram bot, **@the_Jennie_bot**, for Hangeul Korean Language & Visa (HKLV), a study-in-Korea agency in Dhaka. It runs on one Windows 10 PC (Ryzen 5 8600G, RTX 5060 8 GB, Python 3.12) and reads the agency's PHP admin portal `https://hangeul.com.bd/admin` **strictly read-only** (httpx GETs plus the one login POST, parsed with BeautifulSoup after Cloudflare's hidden e-mail addresses are decoded). It answers about 25 commands (42 command names with their aliases) and free-text questions (verified payments, consultation requests, pending payments, window applications, dashboard figures, intakes, admitted students, calendar deadlines, passport cross-checks by OCR, stages, missing information, and the portal's own **Consultant Performance** page for today or this month), sends a factual daily brief at 18:05, alerts on passport scans that disagree with the portal (a 30-minute OCR watcher), keeps one Google Sheet per program and intake in step with the portal every 15 minutes (with a GPU document/OCR check of newly verified students' files), sends a 09:05 missing-information report, refreshes passport issue dates at 08:30, can draft and send an e-mail to a student after explicit approval, and exposes a small REST API on port 8000. Since 30 Sep 2026 22:27 it also **publishes everything it reads or builds to Supabase** (project `dcbcbpwpmdtaanboetiz`: structured rows, text and 384-number gte-small embeddings, made on the CPU in separate processes, plus an hourly "full picture"), so the owner's phone assistant **Jeannie** can answer from it; a Supabase failure is one log line and never touches Telegram, Sheets or Drive. A local LLM (`qwen3:4b-instruct` via Ollama, loaded on demand) never states a figure: it picks facts, drafts e-mails and writes one checked summary sentence. A voice assistant, "Jennie" (Telegram voice notes in, a cute Korean/English voice note out, via a local faster-whisper + CosyVoice2 service), is fully built and **switched off** since 28 Sep 2026 17:08 to free GPU memory.

## 2. How to use this pack

- **It is a blueprint to copy.** Every file gives exact paths, function signatures, data shapes, regexes, CSS selectors, schedule times, message formats and error rules, with `path:line` at `8317741`, plus *why* each choice exists. Where the repository's own docs (`README.md`, parts of `MIGRATION.md`, the guardrails file's "Currently N" figures, some docstrings) are stale, the pack follows the code and says so ([11 §B22](11_OPEN_ITEMS_AND_KNOWN_LIMITS.md), [03a §9](03a_FILES_src_bot.md)).
- **Secrets:** the actual credentials exist only as exact file copies in [`secrets\`](secrets/README.md): `bot.env` (= `C:\Hangeul\BOT\.env`, re-copied on 30 Sep, including the Supabase secret key and the account-wide Supabase personal access token), `credentials.json`, `token.json`. Every document refers to a secret as "value in secrets/bot.env (KEY_NAME)" and never shows it. **Delete the `secrets\` folder before sharing the pack with anyone or giving it to a hosted AI.** A new bot gets its **own** credentials; for this bot the owner has deferred rotation (D13) and asked not to be urged to rotate ([secrets/README.md](secrets/README.md) §4, [11 B7](11_OPEN_ITEMS_AND_KNOWN_LIMITS.md)).
- **No student personal data** appears anywhere: names, phones, e-mails, passport numbers and dates of birth are placeholders (`<student name>`, `<uid>`, `HNG-YYYY-NNN`, `<passport no>`). Supabase itself holds full student data by the owner's decision D1, but no record is quoted here. Figures such as "340 students" or "1,034 requests" are live aggregates of 28-30 Sep 2026, given for orders of magnitude. Staff appear by role; the consultants in the performance examples of [05 §5.15](05_TELEGRAM_COMMANDS_AND_JOBS.md) and [03a §6a](03a_FILES_src_bot.md) appear only as placeholders (`<consultant A>` …).
- **Paths** are Windows paths as they are on this PC. **Times** are Asia/Dhaka (UTC+06:00).
- **Read-only:** nothing in this pack asks you to write to the portal; the bot never does. Its only writes outside the PC are Telegram messages, the Google Sheets and Drive folders, one approved e-mail, and the Supabase rows (through `hg_sync` only).
